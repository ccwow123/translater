# 多后端文本翻译工具

一款多功能 Windows 桌面翻译工具：支持自定义的翻译后端，可**实时翻译、批量翻译、编辑译文与反翻译**并保存。
图形界面（Tkinter）、拖拽加载、断点续传、换保留排版，全程**不依赖任何第三方 pip 包**。

## 功能特性

- **多后端分组可选**：
  - *LLM 对话模型*：硅基流动、LM Studio 本地、自定义·xxx（OpenAI 兼容接口，可自由增删重命名保存）
  - *专用翻译 API*：百度翻译、腾讯云机器翻译、阿里云机器翻译、彩云小译
- **单文件翻译**：实时显示原文/译文，或直接导出到文件
- **反翻译**：在双向编辑中把译文翻回原文，核对翻译质量
- **批量翻译**：文件夹批量或读文件列表（.txt），两段式流程，弹出队列窗口，含暂停/继续/停止
- **断点续传**：单文件翻译中断后从半成品续翻
- **换保留排版**：Markdown 代码块 / 表格 / 标题 / 列表原样保留，并校验段落数防止 AI 吞段
- **拖拽加载**：把文本文件直接拖进窗口即自动载入输入区
- **安全存储**：全部 API 密钥用 Windows DPAPI 加密后存入配置文件，日志不含任何密钥

## 运行

双击 `modular/run_gui.bat`（或桌面快捷方式「自由翻译器.lnk」）。按钮自动选择已配好的 Python 环境，静默启动、不弹命令行窗口。


## 使用方法

### 一、单文件翻译（实时）
1. 点击「**从文件加载**」选择要翻译的文件，或将文件**直接拖拽**到窗口。
2. 选择「**翻译后端**」（下拉框已按 *LLM 对话模型* / *专用翻译 API* 分组），设置**源语言 / 目标语言**，并填写对应平台的**后端参数**（API Key、模型、地域、系统提示词等）。
3. 点击「**翻译**」：结果只显示在输出区，不落盘。
   点击「**翻译并导出**」：按导出规范保存到文件（见下）。
4. 可在「**双向编辑**」中对照原文与译文人工调整，或执行反翻译。

### 二、反翻译
在「双向编辑」中对译文执行「译文 → 原文」反向翻译，用于核对 AI 是否忠实还原、验证翻译质量。

### 三、批量翻译
1. 点击「**批量翻译**」，选择输入方式：
   - ① **选择文件夹**：读取该文件夹下全部文本文件。
   - ② **读取文件列表**：选一个 `.txt`，每行一个文件地址，`#` 开头的行会被忽略。
2. 文件进入待处理列表后，点击「**翻译并导出**」**才开始真正的翻译**。
3. 翻译时弹出「**批量文件队列**」窗口，实时显示每个文件状态（待处理 / 正在处理 / 已完成 / 结构异常 / 失败），并提供：
   - **暂停 / 继续**：临时挂起队列（在文件边界真正等待）。
   - **停止**：中断当前文件并停止剩余队列，已完成文件保留。
4. 结束后自动生成**翻译报告**到桌面，汇总成功 / 结构异常 / 失败数量与清单。

### 四、平台密钥配置
- 各平台密钥在对应后端的参数表单里填写，保存时用 **Windows DPAPI 加密**（绑定当前用户 + 本机）。
- LM Studio 本地：默认指向 `127.0.0.1`，无需密钥。
- 自定义 OpenAI 兼容平台：可通过「**管理自定义平台**」增删、重命名并预填 OpenAI 官方模板。
- 每个后端均有「**测试连接**」按钮，点击真实调用一次以验证密钥与模型可用。

## 导出规范（README 为唯一依据）

> 翻译/导出行为严格遵循本文件约定。后续如需调整导出规则，请改本文件并同步代码。

1. **单文件导出**：命名 `原文件名-目标语言翻译.原扩展名`，保存到**原文件所在目录**。
   例：`article.md` 译为中文 → `article-中文翻译.md`
2. **批量导出**：每个文件按同一规则存到**各自原文件所在目录**（保留原目录结构），不集中另建输出目录。
3. **翻译报告**：批量结束后汇总到**桌面**，文件名为 `翻译报告_时间戳.txt`，列出成功 / 结构异常 / 失败清单。
4. **断点续传**：中断时半成品译文以 JSON 暂存，下次续翻，不覆盖已完成文件。
5. **失败处理**：批量中每个文件自动重试 3 次（间隔 2 秒）；停止后仅保留已完成文件。

## 日志

每次启动在 `log/` 生成唯一文件：`translate_YYYYMMDD_HHMMSS.log`，记录应用启动、文件加载、翻译事件与异常堆栈。日志**不包含**任何 API 密钥。

## 卸载/清理

- 配置与密钥存于 `~/.translate_gui_config.json`（密钥为 DPAPI 密文）。删除该文件即清除全部本地配置与密钥。
- DPAPI 密文绑定本机与当前用户，重装系统后需重新填写密钥。
